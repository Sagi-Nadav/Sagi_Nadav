כפיפה (Bending)

נוסחאות כפיפה

d = h - c - phi/20 [cm]
Mcd_max = 0.32 * b[m] * d[m]^2 * fcd [t.m]
mu = Md / (b * d^2 * fcd)
omega = max(0.1, 1 - sqrt(1 - 2*mu))
As = Md / (d[m] * (1 - omega/2) * fsd/100) [cm2]

גזירה (Shear)

נוסחאות גזירה

K = min(1 + sqrt(200/d_mm), 2)
rho_l = min(As/(b*d), 0.02)
Vrd_c = 0.12*K*(100*rho_l*fck)^(1/3)*b[m]*d[m]*100 [ton]
Vrd_max = 0.18*(1-fck/250)*fck*0.9*b*d*100 [ton]
Asv/sv = (Vd-Vrd_c)/(fsd*0.9*d[m]) [cm2/m]

עיגון (Anchorage)

נוסחאות עיגון

fbd = 2.25 * eta1 * fctd [t/m2]
lb_rqd = (phi/400) * (fsd/fbd) [m]
lb_min = max(0.3*lb_rqd, 10*phi/1000, 0.10) [m]

קירות (Walls)

נוסחאות קירות

lambda = factor * H[cm] / t[cm]
Nrd = fcd * (t/100) * (1-(lambda/86.6)^2) [t/m]
Nser = Nrd / 1.45 [t/m]

עמודים (Columns)

נוסחאות עמודים

A = b * h [cm2]
Nrd = (rho/100*fsd + (1-rho/100)*fcd) * A/10000 [ton]
Nser = Nrd / 1.55 [ton]
